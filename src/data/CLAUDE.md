# Venue data rules

- `venues.ts` is the single source of truth for venue info. It's edited both
  by hand and by the photo scraper.
- Every price, capacity, and factual detail must come from a real, verifiable
  source: the venue's official site, hkwvdb.com, weddinghk.hk, or
  baby-kingdom.com forums. Never estimate or invent numbers — if you can't
  verify a field, leave it out; if you can't verify the venue, don't add it.
- `pricePerHead` is per-guest HKD (per-table price ÷ 12). `tables` is min/max
  table count, ~12 guests per table.
- Keep venue property lines indented exactly 4 spaces (the file's normal
  2-space nesting) — `scripts/build-venue-lines.ts` finds each venue with the
  regex `^\s{4}id:`, and the site's "Edit on GitHub" links break if
  indentation drifts.
- `venue-lines.json` is generated by that script before every dev/build run —
  never edit it by hand.
